# Paper

This directory contains an **anonymized Markdown reconstruction** of the course paper used as the source for the 20-claim evaluation.

## What was removed

- cover page, author name, student ID, university/college, class, course name, semester
- instructor comments, score, signature
- course assignment statistics at the end
- the original `.doc` file and its metadata

## What is included

- title, abstract, keywords
- sections 1–4
- table 1 and table 2
- the 11 public references
- the full C code appendix
- the three original console-output screenshots

## Notes

- This is a course paper, not a peer-reviewed publication.
- The paper is included for context only; the evaluation uses the 20 short claims in [`../data/claims.json`](../data/claims.json).
- The console output in attachment 2 contains both the **full Topo** and **simplified Topo** columns. Table 1 in the paper uses the simplified column; the original screenshot is kept intact for transparency.
- The original `.doc` is intentionally not included.

Read the anonymized paper: [paper-anonymized.md](paper-anonymized.md).
